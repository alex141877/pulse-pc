PulsePC

Ajouter un PC

Sur le PC Debian, avec Tailscale connecté, exécute dans un terminal :

sudo apt-get update
sudo apt-get install -y git python3
pulsepc_dir=$(mktemp -d)
git clone --depth 1 --branch v2.3.0 https://github.com/alex141877/pulse-pc.git "$pulsepc_dir"
sudo sh "$pulsepc_dir/install-debian.sh" --enable-power
sudo tailscale serve status

Si aucun service Serve n’est configuré sur ce PC :

sudo tailscale serve --bg http://127.0.0.1:8765

Génère ensuite le jeton à coller dans PulsePC :

sudo python3 /opt/pulsepc/pair.py
